# Portal de Consulta Previdenciária (V2 - Local)

Este projeto foi simplificado para funcionar de forma 100% independente, utilizando arquivos JSON locais para o banco de dados de processos.

## 🚀 Como Funciona
- **Busca:** O site lê diretamente os arquivos `vtc_queue.json` e `8_andamento.json`.
- **Independência:** Não requer conta no Supabase ou outras dependências externas.
- **Manutenção:** Para atualizar os dados, basta editar os arquivos JSON e enviar para o GitLab.

## 🛠️ Tecnologias
- HTML5 / CSS3 (Bootstrap / Glassmorphism)
- JavaScript (Fetch API para dados locais)
- GitLab Pages (Hospedagem gratuita e segura)
- Supabase (PostgreSQL / REST API).
- **DevOps**: GitLab CI/CD, GitLab Pages.
